# B 提供给 A 的首轮实验与交接方案

本方案只规定实验要记录什么和如何证明标签；A 负责设备执行与原始记录。环境、倾角、流量或告警的物理阈值均为 `TODO_CALIBRATION`，不得从旧七字段演示规则抄数值。

| 建议 run_id | 操作目的 | 可用标签及证据 | 必须特别记录 |
|---|---|---|---|
| `run_001_normal` | 静止、无降雨基线；重复装夹以检查偏置 | 有操作日志证实的稳定区间为 `NORMAL` | top/toe 静止姿态、土壤初始状态、安装照片、基线时段 |
| `run_002_rain_light` | 实验轻档降雨，观察探针响应传播 | 经操作记录证实的降雨区间可标 `RAIN` | 真实 rain_level、开始/结束时间、实际流量；不能因潮湿自动标滑移 |
| `run_003_rain_medium` | 实验中档降雨，与轻档比较 | 经操作记录证实的降雨区间可标 `RAIN` | 实际 rain_level/flow；如果发生滑动需另记录证据和区间 |
| `run_004_vibration` | 可控敲击/振动，验证双 IMU 与误报 | 无滑移证据时不能标 `SLIP`；有证据的稳定区间可标 `NORMAL`，不确定段留空 | 敲击次数、时刻、位置、力度/工具、影像与实际地表状态 |
| `run_005_small_slip` | 受控小滑移，检查事件前后特征 | 只将人工/影像确认的实际滑移区间标 `SLIP`；不确定前兆留空或按真实现象标注 | 滑移开始/结束与标注者、视频、物理位移观察、重置动作 |

每次重复应使用新的 `run_id`，并用 `parent_run` 或等价来源记录把同一原始实验的派生片段、增强数据和合成后代关联起来。首五种实验是覆盖场景的起点，不是五条记录，也不足以证明模型泛化。B 收到重复 run 后才确定按组切分的独立真实 Test。

交接时请 A 一起提供：原始 20 列 CSV、文件 SHA-256、设备与 boot 身份、固件版本、`row_index→uptime`、各通道真实采样时刻和 validity/I2C 错误、IMU ODR/滤波/量程/方向、ADS1115 PGA、三根土壤探针逐支校准、操作与标签区间来源。换装、重启、时钟校正、采样率切换应显式记为事件。文件结构可先按 A 实际日志保留，B/C 三方再冻结元数据结构；不能为通过程序自行编造字段值。

运行 `data_intake/check_experiment_csv.py` 后，把质量报告与原文件一起留档。报告中的 `CSV_CHECKED` 仅表示当前脚本完成结构/数值/时间初检；B 仍需核对元数据、物理范围、漂移、饱和、有效采样率与标签可信度，再决定是否进入特征表。若脚本报告倒退、重复、空值或异常变化，先对照 A 日志调查，不覆盖原始 CSV。
