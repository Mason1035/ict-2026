# 三路 Air–Water 应用集成

本轮将团队最新主线合并到张鹏飞分支，接入B的2026-11-22参数。全部代码在原仓库内，构建/测试记录位于E盘07_整理记录，页面结果位于03_分析结果，不在根目录散放文件。

## 已实现

- 后端从B唯一参数文件读取三路新端点，不复制维护另一套常量。新增独立soil_calibration元数据和features.soil_w_rel_pct，不修改冻结Telemetry和原始risk。
- 三路最新相对百分比及三条历史曲线显示版本、缺测、越界及适用状态；旧结果不自动重算，不跨boot或参数版本连接曲线。
- 连接器支持可清空的firmware_elf_sha256，必须为小写64位十六进制，必须绑定单设备Topic；仅传入接入sidecar。未知/旧固件不套新端点，保持空值。该声明来自操作者，不能视为设备认证，需从实际设备/原件核对，不能照抄期望值。
- 旧土壤0.60/0.85演示阈值停用。三路仅展示，不以浸水或相对百分比直接推断灾害。IMU仍为未标定演示逻辑，整体calibration_version=null、fusion_eligible=false。

## 本地运行

当前机器已在platform_backend/.venv准备应用环境，并完成前端构建。PyCharm打开仓库，运行scripts/run_platform_local.py；浏览器访问http://127.0.0.1:8000，API文档为/docs。脚本使用项目内应用虚拟环境，设置UTF-8及本地临时目录；首次换机器须按platform_backend/README.md安装依赖并构建页面。

启动默认仍有明确MOCK演示。需要真实设备时设置GEOHAZARD_DEMO=0，在连接器页面选择REAL和对应用途，填写实际Broker、单设备Topic和已核实的固件哈希。原始校验和正式字段保持不变，不能为绕过校验伪造UTC、会话身份或BEG/END。
