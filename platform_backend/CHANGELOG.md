# Changelog

## Unreleased — 2026-11-13

- 新增独立 PROVISIONAL 实时风险特征、候选土壤指数、等级原因、状态持久化与 latest/history API；隔离于原始 risk、正式 current 与 alarms，异常不阻止遥测入库。
- 页面新增未标定临时风险及趋势、REAL 实时原始曲线、连接器 OPERATIONAL/TEST_ONLY 选项；保留原正式风险展示。
- 支持 GEOHAZARD_HOST LAN 绑定并强制 token，复用浏览器 Bearer 会话；新增板端 Mosquitto/systemd、无构建启动 wrapper、PC dist 复制脚本及中文现场手册。
- SD 回放增加远端 Broker 用户名/密码与环境变量，日志脱敏；补充特征、因果状态、接入隔离、MQTT 回放、LAN 认证与启动回归。

## 0.3.0 — 2026-10-20

- 新增隔离 TinyQuake result.v1 存储、查询、分页和数据流 API；不写入正式遥测或告警。
- MQTT 连接器可选择标准 v2 或 TinyQuake 格式，分别限定 Topic 与身份；参考波形不能标为 REAL。
- 新增本机 USB→MQTT 桥接工具，仅读取实际串口结果，不生成推理数据。

## 0.2.1 — 2026-10-18

- 视觉列表在数据库查询时按设备、来源和相机筛选，新增稳定游标分页与准确总数；避免跨设备配对图像。
- 修复带时区的时间筛选、保留消息处理、异常字符串和连接配置的参数错误。
- MQTT 接收端区分 Broker 链路与接入存储健康，落盘异常不再被显示为成功接收。
- 启动脚本在源码更新后构建最新页面、在依赖变化或首次安装失败后重试；校验解释器与端口。
- 自定义本地端口加入对应 loopback Origin，保持本地访问边界。

## 0.2.0 — 2026-10-16

- 新增 FastAPI 与本地 SQLite WAL 平台，将配置、遥测、接收路径、告警、历史、图像和视觉结果持久化。
- 新增完整 NODE v2 校验、幂等接收、冲突隔离、已知历史会话保护与升级告警。
- 新增实际 Paho MQTT 配置、订阅、握手测试、停止与重连；密码读取脱敏。
- 新增 PNG/JPEG 上传、ROI、质量检查、帧差、SSIM、光流与叠加图，视觉评分保持未标定。
- 为现有 Vue 页面提供后台查询与明确隔离的 MOCK 生产者，保留本地演示模式。
- 保持真实硬件、Atlas、云、正式标定、模型与设备清理确认的未接入边界。
