# Changelog

本记录仅覆盖独立 Web Demo。正式资料与各 Python 模块版本不变。

## 1.2.0 — 2026-10-20

- 新增独立 TinyQuake 实验页：流选择、P/S/Noise 输出、质量、推理耗时与游标历史。
- MQTT 配置支持 TinyQuake 消息格式；参考、实采与正式风险分开展示。
- 超过 30 秒清空实时分数，后端失联清空实验数据；移动布局与六项浏览器检查通过。

## 1.1.0 — 2026-10-18

- 请求超时覆盖完整 JSON / 图片响应体，切换设备或后端后丢弃旧分页、上传及分析响应。
- 视觉证据与结果支持设备/来源筛选及游标加载；参考图与 ROI 改动后明确提示重新分析。
- 示例生成限定到指定 DEMO 设备，MQTT 存储异常与物理连接状态分开展示。
- 补充对应并发、超时、分页和输入变更的定向回归。

## 0.2.0 — 2026-10-16

此处 0.2.0 为当时的平台后端版本；该批次前端包版本仍为 1.0.0。

- 默认入口升级为读取 FastAPI 的多模态平台；原浏览器模拟器保留为明确独立模式。
- 新增 MQTT 配置与实际连接测试、后端场景控制、持久化告警确认、历史 JSON 与游标分页。
- 新增图像上传、参考帧与 ROI、OpenCV 指标、认证媒体和叠加图。
- 区分 MOCK / REAL、未知、过期、断连与未标定状态；后端断开时不自动回落本地演示。

## 1.0.0 — 2026-10-08

- 新建 `apps/geohazard-demo/`，采用 Vue 3、TypeScript、Vite、Three.js、Lucide Vue 和 SVG 图表。
- 以统一模拟状态组合三维边坡、风险、五类遥测、通信链路、模拟控制与事件中心。
- 提供四场景、手动输入、仿真暂停 / 单步 / 倍速、地形模式与监测点详情，以及离线与恢复补传演示。
- 增加明确的 `DEMO_ONLY`、程序化地形、场景雨强 / 裂缝、相对湿润度和 `g` 单位说明。
- 记录本地仓库基线、00 契约 hash、远端最新状态未核实、启动命令与正式项目集成边界。
- 实际验证：TypeScript 检查与 Production Build 通过；12 项引擎测试、19 项 Chrome 浏览器冒烟测试全部通过，主页面无 runtime / console errors 或 warnings。
- 浏览器验证包含四场景、手动参数、通信门控、离线 / 优先补传 / 重试、完整重置、原生对话框及标签键盘操作、reduced-motion 4× 采样、四种宽度与强制 WebGL 不支持时的交互 SVG 后备。
- 保存实际浏览器结果与 1440×900 最终截图。检查范围限独立 Demo，不升级正式项目验证状态。
